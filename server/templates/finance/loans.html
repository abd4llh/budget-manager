How loans work here

The Loan page is a profile around a real loan account

Create the loan as an Account first, with its current amount owed. Then add a Loan profile for APR, regular payment and payoff estimates. The profile does not automatically move money.

Full guide
1 · Create Loan accountAccounts → Add account → type Loan. Set the opening/current debt balance.
2 · Add Loan profileEnter lender, APR, regular payment, start date and payment day.
3 · Record real paymentsBank payments still need a transaction/import. The Loan page then uses the updated account balance for its estimate.
