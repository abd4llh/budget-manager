# Privacy Overview

Budget Manager is designed to be self-hosted.

Financial records, budgets, accounts, imported files and mobile API tokens are stored on the operator's own Budget Manager server. The project does not include a central Budget Manager cloud service.

Optional features can communicate with external services:

- **Enable Banking:** only when the operator configures their own Enable Banking application and authorizes bank account-information access.
- **Android app:** connects directly to the server address selected by the user. LAN discovery uses a local UDP broadcast and returns only server discovery metadata.

A public release should link this document from the repository and clearly distinguish project behavior from the privacy policies of any optional third-party banking provider or hosting/VPN service selected by the operator.
